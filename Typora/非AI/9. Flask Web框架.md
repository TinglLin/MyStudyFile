### 二、连接PyMysql数据库

- **查询不用 commit；增、删、改 必须 commit，否则不生效**

- **参数必须用 % s 占位，禁止拼接字符串**（防 SQL 注入）
- 异常一定要用 `try-except-finally` + `rollback()`



#### 2.1 核心方法（所有CRUD都用这几个）

```python
# 1. 创建连接
conn = pymysql.connect()

# 2. 获取游标
cursor = conn.cursor()

# 3. 执行SQL （增删改查都用）
cursor.execute(sql, 参数)

# 4. 查询多条
cursor.fetchall()
# 5. 查询单条
cursor.fetchone()

# 6. 提交事务（增删改必须写）
conn.commit()

# 7. 回滚
conn.rollback()

# 8. 关闭
cursor.close()
conn.close()
```



#### 2.2 最常用命令

- 条件查询（select）

  ```python
  sql = 'SELECT id,name FROM student WHERE id = %s'
  # 参数是个元组
  cursor.execute(sql,(1,))
  data  = cursor.fetchone()
  ```

  

- 多条查询（selece）

  ```python
  sql = 'SELECT * FROM student'
  cursor.execute(sql)
  data_list = cursor.fetchall()
  ```

  

- 新增（insert）

  ```python
  sql = 'INSERT INTO student(name, age) VALUES(%s,%s)'
  cursor.execute(sql,('zhang',18))
  conn.commit() # 必须提交
  ```

  

- 修改（update）

  ```python
  sql = 'UPDATE student SET age = %s WHERE id = %s'
  cursor.execute(sql,(12,1))
  conn.commit()
  ```

  

- 删除（delete）

  ```python
  sql = 'DELETE FROM student WHERE id = %s'
  cursor.execute(sql,(1,))
  conn.commit()
  ```

### 三、请求Response（响应体）对象

- 学习Flask中视图函数的返回值是如何被转换成HTTP响应
  - **默认响应**：返回字符串时，Flask如何自动生成响应头
  - **自定义响应**：如何通过 **make_response** 和 **Response** 对象来修改响应头（如 Content-Type）
  - **JSON响应**：学习Web开发中最主流的JSON数据格式的三种返回方式



#### 3.1 HTTP协议与响应头基础

- Web服务器返回给浏览器的内容结构，其中**响应头（Response Header）**是关键
  - **Content-Type**：最重要的响应头之一。它告诉浏览器返回数据的媒体类型（MIME类型）
    - text/html：浏览器会将其作为HTML文档解析并渲染
    - text/plain：浏览器会将其作为纯文本，不会解析任何HTML标签
    - application/json：告诉前端这是一个JSON格式的字符串，前端JavaScript可以方便地处理
  - **Status Code：**表示请求的处理结果
    - 1xx：信息响应
    - 2xx：成功响应
    - 3xx：重定向响应
    - 4xx：客户端错误响应
    - 5xx：服务端错误响应



#### 3.2  返回TEXT响应

- 默认情况下，Flask视图函数返回的字符串，会被包装成一个**Response对象**
  
  - 其Content-Type会被自动设置为 **text/html**
- 希望浏览器直接显示源码，而不是解析HTML
  - 就需要修改Content-Type为 **text/plain**
    - 方法1：**使用 make_response**
    - 方法2：直接**创建 Response 对象**

- 方法1：

  ```python
  # 使用 make_response
  from flask import Flask
  from flask import make_response
  app = Flask(__name__)
  
  @app.route('/other')
  def other():
      content = f'<h1>你好 这是我的Other 视图函数!</h1>'
      # 1. 用内容创建Response对象
      response = make_response(content)
  
      # 2. 自定义新的响应头（这是一个字典）
      new_headers = {
          "Content-Type": "text/plain; charset=utf-8",
      }
      # 3. 将自定义头与response关联，.extend会覆盖原有同名字段
      response.headers.extend(new_headers)
      return response
  ```

- 方法2：（更推荐）

  ```python
  # 直接创建 Response 对象
  from flask import Flask
  from flask import Response
  app = Flask(__name__)
  
  @app.route('/other2')
  def other2():
      content = f'<h1>你好 这是我的Other2 视图函数!</h1>'
      response = Response(
          response=content,                     # 响应的文本内容
          status=200,                           # 状态码，通常省略
          headers={"Content-Type": "text/plain; charset=utf-8"}, # 方式1：通过headers字典设置
          content_type="text/plain; charset=utf-8"               # 方式2：直接使用content_type参数，优先级更高
      )
      return response
  ```

  

#### 3.3 返回JSON数据响应

- 现代Web开发（前后端分离）中，后端几乎总是返回JSON格式的数据

- **核心思想**：将Python对象（字典、列表）转换为JSON字符串，并设置正确的Content-Type

  - **构造数据：**Python字典（表示单个对象）或包含字典的列表（表示对象数组）
  - **转换格式：**使用 **json.dumps()** 将Python对象转为JSON字符串
  - **设置响应头：**创建Response对象时，设置**content_type="application/json"**

- 关键代码：

  ```python
  # 省略视图函数前半部分
  # 数据user = dict{}
  # 数据user_list = list(dict{},dict{})
  # 转换为JSON字符串
      json_str = json.dumps(user)
      # 或
      json_str = json.dumps(user_list)
  # 返回Response，并设置正确的Content-Type
      return Response(response=json_str,content_type="application/json; charset=utf-8")
  ```

- 简化写法1：使用元组返回（**body, status, headers**）

  ```python
  # Flask允许从一个视图函数返回一个元组，
  # 格式为 (响应体, 状态码, 响应头字典)。
  # 它会自动为你包装成Response对象
  @app.route('/json3')
  def json3():
      users = [{'name': 'jack', 'age': 22}, {'name': 'yoyo', 'age':20}]
      json_str = json.dumps(users)
      # 自定义一些额外的响应头（比如给前端用的标识）
      custom_headers = {
          "Content-Type": "application/json; charset=utf-8",
          "X-My-Custom-Header": "hello world"  # 自定义头通常以 X- 开头
      }
      # 直接返回一个元组: (响应体, 状态码, 响应头)
      return json_str, 200, custom_headers
  ```

- 简化写法2（最常用）：直接返回字典或列表

  ```python
  # 从Flask 1.1.0开始，如果视图函数直接返回一个字典或者由字典组成的列表，
  # Flask会自动调用json.dumps()进行转换，
  # 并自动将Content-Type设置为 application/json
  # 目前最推荐、最符合Python风格的写法
  @app.route('/json4')
  def json4():
      # 直接返回Python对象（字典或列表），Flask会智能处理
      users = [
          {'name': 'jack', 'age': 22, 'sex': 'male'},
          {'name': 'yoyo', 'age': 20, 'sex': 'female'},
          {'name': 'tom', 'age': 21, 'sex': 'male'}
      ]
      # 不需要json.dumps，不需要手动创建Response！
      return users
      # Flask内部自动完成：users -> json字符串 -> Content-Type: application/json
  ```

  

### 四、请求Request（请求体）对象

- **知识点总结表**

| 要获取的信息 | 代码示例                | 说明                   |
| ------------ | ----------------------- | ---------------------- |
| 请求方法     | request.method          | 返回 'GET', 'POST' 等  |
| 请求头       | request.headers         | 返回所有请求头信息     |
| 请求路径     | request.path            | 不包含域名和参数       |
| 完整URL      | request.url             | 包含所有信息           |
| GET参数      | request.args.get('key') | 获取URL中的查询参数    |
| POST参数     | request.form.get('key') | 获取请求体中的表单数据 |
| 路径参数     | 路由中的<变量>          | 直接作为函数参数       |
| 类型转换     | tpye=int                | 自动转换参数类型       |
| 默认值       | default=' '             | 参数不存在时的返回值   |

- **最佳实践建议**
  - 选择合适的请求方式
    - 获取数据用GET：GET /students?class=1
    - 提交/修改数据用POST：POST /students
  - 参数分类使用
    - 资源标识用路径参数：/student/123
    - 过滤条件用查询参数：?age=18&sex=male
  - 总是提供默认值
    - 好的做法：name = request.args.get('name', default='')
    - 不好的做法：name = request.args.get('name')  # 可能为None
  - 善用类型转换
    - age = request.args.get('age', type=int)  # 自动转换为int，避免手动转换的麻烦和异常



#### 4.1 获取请求的原信息

- Flask会将每一个HTTP请求封装成一个request对象，
- 在视图函数中可以直接**使用 request.属性名** 获取请求的各种信息

```python
from flask import Flask, request

@app.route('/get_request')
def get_request():
    # 1. 查看请求头（最全面的信息）
    print(request.headers)      # 打印所有请求头信息
    print(type(request))        # <class 'flask.Request'>
    
    # 2. 获取请求方法
    print(request.method)       # GET / POST / PUT / DELETE 等
    
    # 3. 获取请求路径（不含域名和参数）
    print(request.path)         # /get_request
    
    # 4. 获取完整路径（含查询字符串）
    print(request.full_path)    # /get_request?name=jack&age=18
    
    # 5. 获取完整URL
    print(request.url)          # http://127.0.0.1:5000/get_request?name=jack&age=18
    
    # 6. 获取基础URL（不含查询参数）
    print(request.base_url)     # http://127.0.0.1:5000/get_request
    
    # 7. 获取查询字符串（?后面的原始内容）
    print(request.query_string.decode())  # name=jack&age=18
    
    return 'Hello World!!! 2026'
```



#### 4.2 GET请求参数获取

- GET请求的参数通常附加在URL的**?后面，格式为 key1=value1&key2=value2**
- Flask通过**request.args**来获取这些参数
- 核心语法：
  - **request.args.get(key, [default=None], [type=None])**
    - key：参数名（必需）
    - [default]：参数不存在时返回的默认值（可选）
    - [type]：类型转换函数（可选）
- 关键点：
  - 所有参数默认都是**字符串**类型
  - 使用 type 参数可以自动转换类型，但转换失败会得到 None
  - 使用 default 参数可以避免参数不存在时的 None 值

```python
# 完整示例
#也就是说add_stu函数是与/add_stu路径绑定，并确定/add_stu的methods=['GET']
@app.route('/add_stu', methods=['GET'])
def add_stu():
    # 模拟Web请求的URL地址:
    # xxx/add_stu?sid=1&stuno=JSJ001&stuname=jack&stusex=male&stuage=20&stubirth=2006-3-4&stuscore=90.5
    
    # 基础用法：获取字符串参数
    stuno = request.args.get(key='stuno', default="")     # 默认值为空字符串
    stuname = request.args.get(key='stuname')             # 不存在则返回None
    stusex = request.args.get(key='stusex', default="male")  # 默认值为"male"
    
    # 高级用法：自动类型转换
    sid = request.args.get(key='sid', type=int)           # 转为int类型
    stuage = request.args.get(key='stuage', type=int)     # 转为int类型
    stuscore = request.args.get(key='stuscore', type=float)  # 转为float类型
    stubirth = request.args.get(key='stubirth')           # 字符串类型
    
    print(sid, stuno, stuname, stusex, stuage, stubirth, stuscore)
    
    # 返回JSON格式的响应
    result = {
        "code": "success",
        "message": "add stu success"
    }
    return result  # Flask会自动转为JSON
```



#### 4.3 路径参数获取

- 路径参数是URL的一部分，通过路由中的 <变量> 来定义
- 这种方式常用于资源定位，如 /user/123 表示ID为123的用户

```python
# 路径参数定义：<类型:变量名>
# 路径参数：<int:sid>，int型sid数据
@app.route('/update_stu/<int:sid>', methods=['POST'])
def update_stu(sid: int):  # sid直接作为函数参数传入
    # sid是通过URL路径传递的，不需要从request中获取，可以直接使用sid参数
    print(f"正在更新学号为 {sid} 的学生信息")
```



#### 4.4 POST请求参数获取

- 从请求体中获取表单数据

- POST请求的参数不在URL中，而是放在**请求体（Request Body）**里

- Flask通过 **request.form** 来获取这些数据

  - 这种方式更安全，也能传递更多数据

- 核心语法：

  - **request.form.get(key, default=None, type=None)**
    - key：参数名（必需）
    - [default]：参数不存在时返回的默认值（可选）
    - [type]：类型转换函数（可选）

  ```python
  # 完整示例：
  @app.route('/update_stu/<int:sid>', methods=['POST'])
  def update_stu(sid: int):
      """
      混合参数传递示例：
      - 路径参数：sid（用于定位要更新的学生）
      - 表单参数：其他学生信息（通过POST请求体传递）
      
      测试URL（使用POSTMAN）：
      http://127.0.0.1:5000/update_stu/1
      在Body中选择 form-data，添加以下参数：
      - stuno: JSJ001
      - stuname: jack
      - stusex: male
      - stuage: 20
      - stubirth: 2006-03-04
      - stuscore: 90.5
      """
      
      # 从路径参数获取（URL中）
      print(f"更新学生ID: {sid}")
      
      # 从请求体获取（POST表单数据）
      stuno = request.form.get(key='stuno', default="")
      stuname = request.form.get(key='stuname')
      stusex = request.form.get(key='stusex', default="male")
      stuage = request.form.get(key='stuage', type=int)
      stubirth = request.form.get(key='stubirth')
      stuscore = request.form.get(key='stuscore', type=float)
      
      print(stuno, stuname, stusex, stuage, stubirth, stuscore)
      
      # 返回JSON响应
      result = {
          "code": "success",
          "message": f"update stu {sid} success"
      }
      return result
  ```

  

#### 4.5 GET vs POST

| 特性     | GET请求                     | POST请求                     |
| -------- | --------------------------- | ---------------------------- |
| 参数位置 | URL的?后面（查询字符串）    | 请求体（Request Body）       |
| 数据获取 | request.args                | request.form                 |
| 安全性   | 较低，参数暴露在URL中       | 较高                         |
| 数据长度 | 有限制（浏览器/服务器限制） | 无限制                       |
| 缓存     | 可以被缓存                  | 不会被缓存                   |
| 书签     | 可以保存为书签              | 不能保存为书签               |
| 测试工具 | 浏览器地址栏直接测试        | 需要POSTMAN等工具            |
| 典型用途 | 查询、过滤、分页            | 提交表单、上传文件、修改数据 |

### 六、蓝图Blueprint

- 蓝图是Flask中用于组织一组相关路由的容器，类似于"子应用"或"模块化App"

- `Blueprint(name, __name__)`

  ```python
  # 蓝图的基本使用流程：
  from flask import Flask, Blueprint  # 可以一次性导入 Blueprint
  import settings
  
  app = Flask(__name__)
  app.config.from_object(settings)  # 加载配置
  
  # 1. 先定义蓝图 name值必须唯一
  user_bp = Blueprint('user', __name__)
  
  # 2. 在蓝图上定义路由（必须在注册之前完成）
  @user_bp.route('/login')
  def login():
      return 'Login'
  
  @user_bp.route('/profile')
  def profile():
      return 'User Profile'
  
  # 3. 注册蓝图到 Flask 应用（所有路由定义完成后再注册）
  app.register_blueprint(user_bp, url_prefix='/user')
  
  if __name__ == '__main__':
      app.run(host='0.0.0.0', port=5000, debug=True)
  # http://192.168.0.61:5000/user/login
  # http://192.168.0.61:5000/user/profile
  ```

#### 6.2 `app/__init__.py`代码详解

- 应用工厂
- **应用工厂模式**：用一个函数来创建和配置Flask应用，而不是在全局作用域直接创建

```python
from flask import Flask
from apps.user.views import user_bp      # 导入用户模块的蓝图

"""应用工厂函数：创建并配置Flask应用"""
def create_app():
    # 1. 创建Flask核心对象
	app = Flask(__name__)
    
    # 2. 加载配置（从settings.py文件）
	app.config.from_object(settings.py)
    
    # 3. 注册蓝图（模块化路由）
    # url_prefix：为蓝图中的所有路由添加统一前缀
    # 用户模块路由以user_bp中的蓝图内部名称，即/user开头
	app.register_blueprint(user_bp, url_prefix='/user')
    
    # 4. 返回配置好的app对象
```



#### 6.3 app.py代码详解

- 应用入口：app.py
- 这是整个应用的启动文件，职责非常单一：**调用工厂函数创建应用，然后启动服务器**

```python
from apps import create_app  # 从apps包导入工厂函数
```

### 七、Flask 的 cookie

  ```python
  from flask import Flask, make_response

      key:'key_name'

  )
  ```

- **Request请求**的cookie设置

  ```python
  from flask import request
  # 获取浏览器客户端所有cookie
  ```

- 服务端session，flask-session，redis

  - `Session(app)` 是**Flask 框架**中**启用服务端会话**的核心代码，作用是给 Flask 应用绑定**服务端 Session 功能**

  - **归属**：属于 `flask-session` 扩展（不是 Flask 原生自带）

  2. **作用**
     
     - 替代 Flask 默认的**客户端 Cookie 会话**
     - 把用户的会话数据**存在服务器端**（内存/Redis/数据库等）
     - 客户端只存一个无意义的会话 ID，更安全
     
  3. **用法逻辑**
     ```python
     from flask import Flask
     from flask_session import Session

     app = Flask(__name__)
     Session(app)  # 绑定服务端会话到应用
     ```
     
  4. **本质**：初始化一个会话管理对象，接管应用的 `session` 变量，让数据存在服务端。
